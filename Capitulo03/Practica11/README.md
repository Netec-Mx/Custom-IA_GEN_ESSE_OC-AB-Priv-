# Práctica 11. Analizar una base de datos comercial con Advanced Data Analysis para identificar tendencias de venta, oportunidades de negocio y elaborar un reporte ejecutivo dentro de Canvas

**Duración de la práctica:** 30 minutos

> **Nota técnica sobre la interfaz y el plan:** En las cuentas de ChatGPT con plan Gratuito (Free), las herramientas avanzadas de ejecución de código (como Advanced Data Analysis / intérprete de Python) y la carga directa de archivos tabulares externos se encuentran restringidas o no están disponibles de forma nativa en el panel de herramientas. Por esta razón, todo este laboratorio se ejecuta íntegramente mediante **instrucciones conversacionales en lenguaje natural (prompts)** en la barra de chat estándar, logrando que la inteligencia artificial autogenere los datos, procese las métricas analíticas y redacte los informes gerenciales de manera completamente autónoma.

## Descripción
Los participantes utilizarán la interfaz estándar de ChatGPT mediante prompts especializados para generar, simular y procesar de manera totalmente autónoma una base de datos transaccional de ventas, identificar tendencias comerciales ocultas, detectar oportunidades de negocio mediante segmentación y redactar un reporte ejecutivo completo para la dirección general.

---

## Sección 1: Demostración del Instructor - Tres Pasos

1. **Autogeneración del conjunto de datos comerciales en el chat:**
   * Abre ChatGPT en tu plan gratuito y envía la siguiente instrucción para que el modelo cree los registros de ventas simulados de forma autónoma:
     ```text
     Actúa como un Administrador de Operaciones de Ventas.
     Genera de manera completamente autónoma un conjunto de datos estructurado en formato tabular de texto
     con quinientas transacciones comerciales simuladas de una empresa B2B,
     incluyendo columnas de fecha, cliente, región, producto, cantidad, precio unitario y monto total.
     Muestra las primeras diez filas para verificar la integridad de los datos creados.
     ```

2. **Ejecución de análisis de tendencias y estacionalidad mediante lenguaje natural:**
   * Solicita al modelo procesar el comportamiento de las ventas con el siguiente comando:
     ```text
     Actúa como un Analista de Inteligencia de Negocios.
     A partir de la tabla de transacciones generada anteriormente, calcula el crecimiento mensual de las ventas,
     identifica las tres regiones con mayor volumen de facturación
     y determina las categorías de productos con mayor margen de ganancia.
     ```

3. **Generación automática del reporte ejecutivo para la gerencia:**
   * Finaliza la demostración estructurando los hallazgos con la siguiente instrucción:
     ```text
     Actúa como un Director de Operaciones Comerciales.
     Con base en los cálculos analíticos anteriores, redacta un informe ejecutivo de tres párrafos
     dirigido a la Dirección General que resuma el rendimiento del periodo,
     señale la principal oportunidad de expansión detectada y proponga un plan de acción comercial inmediato.
     ```

---

## Sección 2: Práctica Guiada del Participante - Cinco Pasos

1. **Autogeneración del volumen transaccional de prueba en la sesión de chat:**
   * Abre una nueva conversación en ChatGPT y envía la siguiente instrucción para crear la base de datos de trabajo de forma completamente autónoma:
     ```text
     Actúa como un Ingeniero de Datos Comerciales.
     Genera de forma completamente autónoma un registro detallado de mil transacciones de venta corporativa
     correspondientes al último año, asegurando que contenga fecha, cuenta cliente, zona geográfica,
     categoría de solución, volumen de compra y monto total facturado.
     Presenta un resumen consolidado de la estructura generada.
     ```

2. **Ejecución de consultas analíticas para la detección de tendencias de venta:**
   * Envía la siguiente instrucción en varias líneas para que el modelo procese el comportamiento temporal de los datos creados:
     ```text
     Actúa como un Analista Senior de Datos Comerciales.
     Utilizando el conjunto de datos simulado en el chat, analiza las tendencias de venta trimestrales,
     determina el mes con mayor volumen de facturación
     y calcula el ticket promedio de compra por cuenta cliente.
     ```

3. **Segmentación de cuentas y detección de oportunidades de negocio:**
   * Solicita al modelo realizar una clasificación comercial mediante el siguiente comando:
     ```text
     Actúa como un Especialista en Estrategia Comercial B2B.
     Analiza la distribución de compras por cliente en los datos generados para segmentarlos
     según su volumen total de facturación en categorías de alto y medio valor.
     Identifica cuáles son las dos cuentas o segmentos que representan la mayor oportunidad de venta cruzada
     para el próximo trimestre.
     ```

4. **Diseño de un cuadro visual de métricas y gráficos textuales de soporte:**
   * Pide la representación visual de los datos directamente en el chat utilizando formato estructurado mediante la siguiente instrucción:
     ```text
     Actúa como un Diseñador de Inteligencia Visual Comercial.
     Basado en los datos analizados, genera dos representaciones visuales utilizando texto estructurado y barras de caracteres:
     1. Un gráfico de evolución mensual de las ventas totales.
     2. Un diagrama de barras horizontales con los cinco productos más rentables.
     Muestra los resultados directamente en la interfaz del chat.
     ```

5. **Consolidación y redacción del reporte ejecutivo final:**
   * Finaliza la práctica compilando todos los resultados en un informe gerencial mediante el siguiente comando:
     ```text
     Actúa como un Director Comercial Corporativo.
     Toma todos los hallazgos del análisis de datos, las tendencias detectadas y las oportunidades de negocio,
     y redacta un informe ejecutivo final estructurado con título, resumen de indicadores clave,
     diagnóstico de riesgos y plan estratégico de crecimiento para la dirección general.
     ```

## Resultado esperado
Una base de datos comercial autogenerada y analizada completamente mediante instrucciones en lenguaje natural en la interfaz estándar de ChatGPT, respaldada por métricas de tendencias, representaciones visuales en texto y un reporte ejecutivo listo para la toma de decisiones gerenciales sin depender de planes de pago ni herramientas de código externas.
