# Práctica 9. Se realizará un análisis automático de datos en Excel con Copilot, se generará un informe ejecutivo en Word a partir de esos resultados y, finalmente, se crearán una infografía y una presentación en PowerPoint

**Duración de la práctica:** 30 minutos

## Descripción
Los participantes utilizarán exclusivamente Copilot Chat para ejecutar un flujo completo de productividad comercial sin depender de complementos adicionales. A partir de registros de ventas simulados en formato tabular, realizarán el análisis automático de indicadores listos para Excel, redactarán un informe ejecutivo estructurado para Word, diseñarán el guion visual de una infografía comercial y estructurarán el esquema completo de diapositivas para una presentación de resultados en PowerPoint.

---

## Sección 1: Demostración del Instructor - Tres Pasos

1. **Análisis automático de métricas comerciales para Excel en Copilot Chat:**
   * Abre Copilot Chat y envía la siguiente instrucción en varias líneas para procesar una tabla de ventas y obtener fórmulas y conclusiones listas para Excel:

     ```text
     Actúa como un Analista Senior de Inteligencia Comercial y Especialista en Excel.
     Analiza los siguientes registros trimestrales de ventas regionales:
     Norte: 120000 dólares vendidos contra una meta de 100000 dólares.
     Centro: 85000 dólares vendidos contra una meta de 110000 dólares.
     Sur: 95000 dólares vendidos contra una meta de 90000 dólares.
     Calcula el porcentaje de cumplimiento de cada región, identifica la desviación total en dólares
     y entrega las fórmulas exactas en español para replicar estos cálculos en una hoja de Excel.
     ```

2. **Generación de informe ejecutivo para Word a partir del análisis en Copilot Chat:**
   * En la misma sesión, solicita a Copilot Chat transformar los hallazgos anteriores en un documento corporativo mediante el siguiente comando:

     ```text
     Actúa como un Gerente Regional de Operaciones Comerciales.
     Con base en el análisis de cumplimiento anterior, redacta un informe ejecutivo de tres párrafos
     listo para copiar y pegar en un documento formal de Word dirigido a la Dirección General.
     Destaca el desempeño sobresaliente de la zona Norte, explica el déficit de la zona Centro
     y propone dos acciones correctivas inmediatas para el próximo trimestre.
     ```

3. **Estructuración de infografía y diapositivas para PowerPoint en Copilot Chat:**
   * Finaliza la demostración solicitando el diseño conceptual de los materiales visuales mediante la siguiente instrucción:

     ```text
     Actúa como un Especialista en Comunicación Visual Corporativa.
     A partir del informe ejecutivo anterior, genera primero el esquema de bloques visuales y datos clave
     para diseñar una infografía comercial de una sola página, y segundo,
     la estructura detallada de cuatro diapositivas para una presentación en PowerPoint
     incluyendo título, puntos clave y sugerencia de gráfico para cada lámina.
     ```

---

## Sección 2: Práctica Guiada del Participante - Cinco Pasos

1. **Generación y análisis automático de base de datos comercial para Excel en Copilot Chat:**
   * Abre Copilot Chat y envía la siguiente instrucción en varias líneas para simular una base de ventas y obtener el análisis automático junto con sus fórmulas de Excel:

     ```text
     Actúa como un Analista de Datos Comerciales y Experto en Microsoft Excel.
     Genera una tabla de ventas semestrales con ocho ejecutivos de cuenta corporativos que incluya:
     Nombre del Ejecutivo, Zona Asignada, Cuota Semestral en Dólares y Ventas Reales Alcanzadas en Dólares.
     A continuación, realiza el análisis automático calculando el porcentaje de cumplimiento individual,
     el promedio general del equipo, los tres ejecutivos con mejor desempeño
     y escribe las fórmulas exactas de Excel necesarias para automatizar toda la tabla.
     ```

2. **Redacción del informe ejecutivo estructurado para documento de Word en Copilot Chat:**
   * En la misma conversación, envía la siguiente instrucción para convertir los resultados de la tabla en un reporte gerencial listo para Word:

     ```text
     Actúa como un Director Nacional de Ventas Corporativas.
     Utilizando exclusivamente los resultados del análisis de ventas generado en el paso anterior,
     redacta un informe ejecutivo formal listo para estructurar en un documento de Microsoft Word.
     Organiza el documento con título corporativo, resumen de hallazgos principales en dos párrafos,
     diagnóstico de brechas frente a la cuota semestral y un plan de acción de cuatro puntos para el siguiente semestre.
     ```

3. **Diseño del contenido y estructura visual de infografía comercial en Copilot Chat:**
   * Solicita a Copilot Chat sintetizar el informe en una pieza gráfica de alto impacto mediante el siguiente comando en varias líneas:

     ```text
     Actúa como un Diseñador de Información Comercial.
     Transforma los datos más relevantes del informe ejecutivo anterior en el guion completo de una infografía comercial.
     Divide la infografía en cuatro secciones visuales claras:
     1. Indicador principal de cumplimiento global.
     2. Podio de los tres mejores ejecutivos de cuenta.
     3. Comparativa visual de desempeño por zona asignada.
     4. Tres metas estratégicas clave para el próximo periodo.
     Detalla los textos breves y el tipo de icono o gráfico sugerido para cada bloque.
     ```

4. **Creación del guion y arquitectura de diapositivas para PowerPoint en Copilot Chat:**
   * Envía la siguiente instrucción multilineal para generar la presentación ejecutiva completa lista para trasladar a PowerPoint:

     ```text
     Actúa como un Consultor de Presentaciones Ejecutivas B2B.
     Con base en el informe de Word y la infografía diseñadas anteriormente,
     estructura una presentación completa de seis diapositivas para Microsoft PowerPoint dirigida al Comité Comercial.
     Para cada diapositiva especifica obligatoriamente:
     - Título de impacto ejecutivo.
     - Máximo cuatro viñetas concisas con los datos clave.
     - Tipo de gráfico o elemento visual recomendado.
     - Notas del orador con el discurso exacto que debe exponer el gerente durante la reunión.
     ```

5. **Validación integral y paquete de transferencia ofimática en Copilot Chat:**
   * Finaliza la práctica verificando la coherencia numérica entre todos los entregables mediante el siguiente comando:

     ```text
     Actúa como un Auditor de Calidad en Operaciones Comerciales.
     Revisa todos los entregables generados en esta sesión para Excel, Word, la infografía y PowerPoint.
     Verifica que las cifras de ventas, porcentajes de cumplimiento y nombres de los ejecutivos
     sean cien por ciento consistentes en todos los formatos
     y entrega una lista de verificación de cinco pasos para ensamblar rápidamente los archivos finales en cada aplicación ofimática.
     ```

## Resultado esperado
Un flujo completo de productividad comercial ejecutado desde Copilot Chat que integra el análisis numérico con fórmulas listas para Excel, un informe ejecutivo estructurado para Word, el guion visual de una infografía de alto impacto y la arquitectura detallada de una presentación ejecutiva en PowerPoint.
